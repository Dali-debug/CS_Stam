# FastAPI Healthcare Wearable Application

Complete MongoDB backend infrastructure for healthcare wearable application built with **FastAPI** (Python) and **Motor** (async MongoDB driver).

## 🚀 Features

- **Real-time Sensor Data Processing** - Handle PPG, IMU, temperature, and EDA data from wearable devices
- **Health Metrics Analysis** - Cardiovascular, activity, stress, and sleep tracking
- **AI Health Risk Predictions** - Multi-category risk assessment
- **AI Health Coach** - Interactive chatbot for health guidance
- **Automatic Data Lifecycle** - TTL indexes for efficient storage management
- **Production-Ready** - Async operations, logging, error handling, validation
- **RESTful API** - 30+ documented endpoints
- **Optimized for MongoDB Atlas Free Tier** - ~100 users, 512MB storage

## 📋 Tech Stack

- **FastAPI 0.109+** - Modern async Python web framework
- **Motor 3.3+** - Async MongoDB driver
- **Pydantic 2.5+** - Data validation
- **Uvicorn** - ASGI server
- **Loguru** - Advanced logging
- **Python 3.11+** - Required

## 🔧 Installation

### Prerequisites

- **Python 3.11+**
- **MongoDB 6.0+** (local) or **MongoDB Atlas** account
- **pip** or **uv** package manager

### Step 1: Create Virtual Environment

```powershell
# Create virtual environment
python -m venv venv

# Activate virtual environment
.\venv\Scripts\Activate.ps1

# If you get execution policy error:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Step 2: Install Dependencies

```powershell
# Install all packages
pip install -r requirements.txt

# Or using uv (faster):
pip install uv
uv pip install -r requirements.txt
```

### Step 3: Configure Environment

```powershell
# Copy environment template
Copy-Item .env.example .env

# Edit .env with your MongoDB connection
notepad .env
```

Update MongoDB URI:
```env
# Local MongoDB
MONGODB_URI=mongodb://localhost:27017

# Or MongoDB Atlas
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/?retryWrites=true&w=majority
```

## 🚀 Quick Start

### Development Mode

```powershell
# Start server with auto-reload
uvicorn app.main:app --reload --port 8000

# Or use Python directly
python -m app.main
```

Server runs at: **http://localhost:8000**

API Documentation (auto-generated by FastAPI):
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

### Production Mode

```powershell
# Start with multiple workers
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

## 🔌 API Endpoints

### Health Checks
- `GET /health` - Application health
- `GET /api/health/database` - Database stats

### Users
- `POST /api/users` - Create user
- `GET /api/users` - List users (paginated)
- `GET /api/users/{user_id}` - Get user
- `PUT /api/users/{user_id}/profile` - Update profile
- `PUT /api/users/{user_id}/goal` - Update goal
- `DELETE /api/users/{user_id}` - Delete user (soft)

### Sensor Data
- `POST /api/sensor-data` - Record sensor reading
- `POST /api/sensor-data/batch` - Batch insert
- `GET /api/sensor-data/{user_id}/latest` - Latest reading
- `GET /api/sensor-data/{user_id}/history` - Historical data

### Health Metrics
- `GET /api/health-metrics/{user_id}/latest` - Latest metrics
- `GET /api/health-metrics/{user_id}/daily-summary` - Daily summary
- `GET /api/health-metrics/{user_id}/trends` - Trends analysis

### Predictions & Notifications
- `GET /api/predictions/{user_id}/latest` - Latest prediction
- `GET /api/notifications/{user_id}` - User notifications
- `PUT /api/notifications/{notification_id}/read` - Mark as read

### AI Coach
- `POST /api/chat/{user_id}/message` - Send message
- `GET /api/chat/{user_id}/history` - Chat history

**Full API documentation**: See [API_DOCUMENTATION.md](./API_DOCUMENTATION.md)

## 🗄️ Database Schema

### Collections

1. **users** - User profiles, medical info, goals
2. **rawSensorData** - Sensor readings (7-day TTL)
3. **processedHealthMetrics** - Calculated metrics (30-day TTL)
4. **dailySummary** - Daily aggregations (365-day TTL)
5. **healthRiskPredictions** - AI predictions (90-day TTL)
6. **notifications** - User alerts
7. **aiCoachInteractions** - Chat history

### TTL Indexes (Automatic Cleanup)

- Raw sensor data: 7 days
- Processed metrics: 30 days
- Daily summaries: 365 days
- Predictions: 90 days
